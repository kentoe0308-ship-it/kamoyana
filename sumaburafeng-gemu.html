オンライン対戦 — ルームコードを入力して合流

友達と2台で対戦するときはここを使います。ホストがルームを作ると4文字のコードが出ます。そのコードを友達に伝え、友達が下の「ルームコードを入力」欄に入れると対戦が始まります。2人ともこのページを開いている必要があります。

ルームに入る（ゲスト）— ルームコードを入力

友達から聞いた4文字をここに入力して「入る」を押してください。

吹っ飛ばしバトル

攻撃を当てて相手の％を溜め、場外へ吹っ飛ばそう。ストック3つ、先に相手を全部落とした方が勝ち。

PLAYER 2（右側の人）

ルール

  • 体力制ではなく％制。攻撃を受けると％が上がり、上がるほど吹っ飛びやすくなる。
  • ステージの外（上下左右）に出るとミスでストックが1つ減る。ストックは3つ。
  • ジャンプは2回まで（2段ジャンプ）。落とされても空中ジャンプと必殺技で復帰を狙える。
  • ガード中はダメージを受けない。必殺技は遠くまで届く飛び道具。

キーボード操作

P1 移動A D
P2 移動← →
P1 ジャンプW
P2 ジャンプ↑
P1 攻撃 / 強 / 技F G H
P2 攻撃 / 強 / 技, . /
P1 ガードS
P2 ガード↓

スマホでは画面下のボタンで操作できます。ローカル2Pをスマホで遊ぶときは、横向きにして2人で左右に分かれるのがおすすめです。

オンライン対戦は PeerJS の公開サーバー経由でブラウザ同士を直接つなぐ方式です。接続できない場合は、2人ともページを開き直して新しいコードで試してください。オンライン中はホスト側の画面が対戦の基準になります。
